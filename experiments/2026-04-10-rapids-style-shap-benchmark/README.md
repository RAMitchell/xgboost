# RAPIDS-Style SHAP Benchmark Models

This directory is used by the paper experiments to define and reproduce the benchmark XGBoost models. Trained model files are intentionally not committed.

## Script

The model metadata is generated by:

```bash
/home/nfs/rorym/anaconda3/bin/conda run -n xgboost \
  python demo/guide-python/quadratureshap_rapids_benchmark.py \
  --model all \
  --model-dir experiments/2026-04-10-rapids-style-shap-benchmark/model-cache \
  --models-only \
  --out-json experiments/2026-04-10-rapids-style-shap-benchmark/models-only-unique-depth.json \
  --out-markdown experiments/2026-04-10-rapids-style-shap-benchmark/models-only-unique-depth.md
```

Use `--force-retrain` to overwrite cached models.

## Committed vs Local Artifacts

Commit the script changes that make this reproducible, but do not commit generated model files or result tables.

Keep local only:

- `model-cache/*.ubj`
- `*.json`
- `*.csv`
- generated `*.md` result tables, unless a small table is deliberately included as paper notes

## Relevant Model Metadata

The paper benchmarks use the `max_unique_feature_depth` column because numerical stress in TreeSHAP-IQ depends on unique feature depth rather than raw tree depth.
